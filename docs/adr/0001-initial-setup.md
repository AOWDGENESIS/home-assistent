# ADR 0001: Initial Setup

## Status
Accepted

## Kontext
Dieses ADR beschreibt die grundlegende Entscheidung, eine strukturierte Home Assistant Konfiguration in diesem Repository aufzubauen.

## Entscheidung
- Nutzung eines klaren Ordnersystems (`configuration/`, `scripts/`, `docs/`)
- Trennung von Konfiguration, Skripten und Dokumentation
- Einführung von ADRs zur Nachvollziehbarkeit technischer Entscheidungen

## Konsequenzen
- Verbesserte Wartbarkeit
- Klare Erweiterbarkeit
- Einheitliche Struktur für zukünftige Änderungen
