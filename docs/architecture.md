# Architekturübersicht

Dieses Dokument beschreibt die grundlegende Struktur und Architektur der Home Assistant Konfigurationen in diesem Repository.

## Hauptkomponenten

- **configuration/**  
  Enthält alle YAML-Konfigurationsdateien.

- **scripts/**  
  PowerShell-Skripte für Setup, Validierung und Deployment.

- **docs/**  
  Dokumentation, Architektur, Komponenten und ADRs.

## Ziele

- Klare Struktur
- Erweiterbarkeit
- Automatisierung
- Nachvollziehbarkeit
